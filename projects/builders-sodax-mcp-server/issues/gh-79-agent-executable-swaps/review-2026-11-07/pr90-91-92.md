### Draft #90 body (assumes the ADR is fixed for items 5 and 6)

```
ADR for #79, the agent-executable swaps epic: how an agent runs a cross-chain swap through this server while the server never signs or holds a key. The swap stack (#91 to #98, then #102) implements it.

[docs/adr/0001-sodax-mcp-execution-model.md](https://github.com/gosodax/builders-sodax-mcp-server/blob/feat/agent-executable-swaps/docs/adr/0001-sodax-mcp-execution-model.md)

The decisions in short:

- D1. Hosted only, no local signing. The server returns unsigned transactions; the agent's wallet tool signs and sends them.
- D2. builders.sodax.com moves behind the same HAProxy edge as the API, so keys and limits are enforced in one place, and the server drops its own inbound limit once the edge is in front. Swap tools need an API key: the server checks its format, the backend checks that it's valid. Builder tools stay keyless; a key, when sent, is forwarded on data API, solver and Swaps API calls, never to the relay.
- D3. Full `@sodax/sdk` and `@sodax/types`, pinned, with overrides for the packages behind the audit advisories. The Swaps API itself is called over REST, since the SDK client retries a 429 at once and drops `Retry-After`.
- D4. Profiles `builder`, `swap` and `all` (default). `SODAX_SWAP_TOOLS_ENABLED` (default true) turns the swap tools off without a deploy.
- D5. Phase 1 sources are the EVM spokes; Sonic, the hub, is refused. Any destination. No `rpcUrl` input.
- D6. Five workflow tools on one action template.

Where it departs from the epic:

- D2. The server refuses a swap connection without a key (403) instead of leaving every check to the gateway, and keeps its own limit until the edge is in front.
- D3. The Swaps API is called over REST, not through `sodax.api.swaps` (reason above).
- Quote. The intent is built with `createIntent`, with an explicit minimum output and deadline. `includeTxData` gives an intent with no deadline and no room for slippage. There is no speed tier; the API has none.
- `sodax_get_balance` takes no `rpcUrl`. A hosted server shouldn't fetch caller URLs, so operators set RPC URLs per chain.

Closes #80
```
